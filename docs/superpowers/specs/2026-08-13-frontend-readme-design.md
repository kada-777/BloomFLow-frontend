# BloomFlow Frontend README Design

## Goal

Create an English `README.md` that gives developers and project reviewers a concise, accurate entry point to the BloomFlow frontend repository.

## Content

The README will contain Project Overview, Technology Stack, Core Features, Local Setup, Environment Variables, Available Scripts, Application Architecture, Backend Integration, Project Structure, Documentation, and License sections.

## Content Rules

- Describe only capabilities, dependencies, and commands verified in the repository.
- Explain role-aware screens without duplicating detailed product documentation.
- Link to the existing API contract, ERD, PRD, and RFC documentation.
- Document `VITE_API_BASE_URL` without exposing credentials.
- Exclude testing content, screenshots, badges, deployment instructions, and endpoint tables.

## Success Criteria

- GitHub renders the README from the frontend repository root.
- A new developer can configure and run the frontend locally.
- A reviewer can quickly understand the stack, features, architecture, backend integration, and documentation layout.
